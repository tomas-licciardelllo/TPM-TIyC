<H1>Hamming and Hufmann project</H1>
This assignment, submitted for the Information Theory and Computation course, demonstrates the application of the Huffman and Hamming algorithms to a text file.
The Hamming algorithm allows encoding in different modules: modulo 8, 1024, and 18368. The Huffman algorithm then compresses and decompresses the bit strings, whether they are strings previously processed by the Hamming algorithm or bit strings containing the text file's contents.
